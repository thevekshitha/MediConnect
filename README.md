# 🩺 MediConnect

An AI-powered healthcare management platform built using Flask that enables patients and doctors to manage appointments, medical records, reminders, and health services from one platform.

---

## 🚀 Features

### 👤 Patient
- Register & Login
- Update Profile
- Upload 
### 👨‍⚕️ DoctorMedical Records
- Book Doctor Appointments
- Medicine Reminders
- AI Symptom Checker

- Register & Login
- Manage Dashboard
- View Appointments
- Update Profile

### 🤖 AI
- AI-powered Symptom Analysis
